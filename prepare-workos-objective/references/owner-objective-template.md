# WorkOS Owner Objective Template Reference

Use these headings, their order, and the supplied choice language exactly.
Replace bracketed prompts with grounded content. For a new project, append the
addendum after Final Direction. For an existing or non-project-specific
objective, omit the addendum from the returned document.

The "Base template" and "Conditional new-project addendum" headings below
organize this reference file; do not copy those two reference headings into the
objective.

## Conditional new-project addendum

For a new project, append only the following content after Final Direction:

Preserve the owner’s actual intent.

- Do not invent requirements or authority.
- Apply explicit corrections and remove retracted dictation.
- Separate owner-stated facts from your assumptions.
- Label unresolved material questions clearly.
- Do not select a technology, cartridge, request ID, or outcome kind.
- Do not rewrite the objective merely to match an existing capability.
- Do not include credentials, secrets, or unnecessary personal data.
- Return one consolidated objective using the supplied template.
